# 🌊 **Tumba la casa submarina** 🎮

---

## 🧩 **Personajes y Modelos**

- **Bob Esponja**: Siempre listo para aventuras con shaders como espiral eléctrico.
- **Casa Piña**: La icónica casa de Bob con un diseño cel-shading único.
- **Patricio**: Tu estrella de mar favorita con efectos de expansión y desintegración.
- **Calamardo**: Elegante y explosivo, con shaders de aura y explosión personalizables.

---

## 🎮 **Controles**

### **Teclado**
- `W/S`: Acercar/Alejar la cámara.
- `↑/↓`: Mover la cámara hacia arriba/abajo.
- `←/→`: Rotar la cámara.
- `Espacio`: Cambiar entre modo de renderizado lleno y alámbrico.
- `1, 2, 3, 4`: Seleccionar personaje (Bob, Casa, Patricio, Calamardo).
- `5`: Restablecer shaders básicos.
- `6`: Aplicar shaders personalizados.
- `P`: Pausar la música.
- `R`: Reanudar la música.
- `M`: Silenciar la música.
- `N`: Ajustar el volumen de la música al 70%.

### **Mouse**
- Botón izquierdo: Controla la rotación de la cámara.
- Rueda: Zoom dinámico.

---

## 🛠 **Cómo Ejecutarlo**

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tuusuario/aventuras-bajo-el-agua.git
   ```
2. Instala las dependencias necesarias:
   ```bash
   pip install pygame
   ```
3. Ejecuta el programa:
   ```bash
   python main.py
   ```
